# Markdown 语法全测

这一篇把常用的 Markdown 写法过一遍，方便对照排版效果，也方便改样式时回归检查。

## 段落与行内样式

普通段落：**加粗**、*斜体*、***粗斜体***、~~删除线~~、`行内代码`、[链接](https://www.11ty.dev)。

行尾打两个空格是段内换行：  
这一行还在上一行的同一个段落里。

转义符号：\*这里不是斜体\*，反引号也可以 \`这样\` 转义。

## 标题层级

正文第一个 `#` 是文章标题（列表页取的就是它），下面这些是正文里的层级：

### 三级标题

#### 四级标题

###### 六级标题

> 一级引用。
>
> > 嵌套的二级引用。
>
> 回到一级，接着写。

## 代码

行内代码 `const x = 1`，以及构建期用 Shiki 高亮的代码块：

```js
module.exports = function (eleventyConfig) {
  eleventyConfig.addPassthroughCopy("src/css");
};
```

```python
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

```haskell
fibs = 0 : 1 : zipWith (+) fibs (tail fibs)
```

不写语言，或者语言不在预载清单里，就退化成无高亮的等宽块：

```
plain text, no highlighting
```

## 没有启用的写法

模板没有引入额外的 markdown-it 插件，GFM 的几样扩展不生效，写了会原样显示成文字：

- 任务列表：`- [ ] 待办` 不会变成勾选框；
- 脚注：`[^1]` 会被当成引用式链接，而不是脚注；
- 定义列表：`术语` 加下一行 `: 说明` 不会解析成 dl。

要用这些，得在 `eleventy.config.js` 里自行 `md.use(...)` 挂上对应的 markdown-it 插件。
